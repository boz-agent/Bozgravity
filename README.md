# Bozgravity Gateway — Landing Page

> Pusat Akses Model AI dalam Satu Key. High-speed, multi-pool API aggregator landing page with Google Antigravity clean white theme & interactive physics particles.

---

## ⚡ TL;DR for AI Agents

PREREQUISITES:
1. Static web host or GitHub Pages / Vercel / Cloudflare Pages.
2. Standard HTML5 browser.

EXECUTION FLOW:
1. Clone repository.
2. Open `index.html` in browser or serve via static file server (e.g. `npx serve` or Python `http.server`).

---

## 🎯 Features

- **Google Antigravity Design System**: Clean white theme, Google Sans typography, and interactive canvas particle engine.
- **Developer-First UI**: Includes macOS Cursor IDE JSON config sample, interactive cURL request terminal, and live cluster monitor.
- **Mobile Responsive**: Built with Tailwind CSS.

## 🛠️ Setup & Deployment

```bash
git clone https://github.com/d4ncboz/bozgravity-landing.html.git
cd bozgravity-landing.html
python3 -m http.server 8000
```
